¿Cómo funciona?

El programa recorre el video cuadro por cuadro y busca los píxeles predominantemente rojos: eso es el Angry Bird. Con el centro de esos píxeles arma una nube de puntos (x, y). Después usa cuadrados mínimos para encontrar la parábola y = ax² + bx + c que mejor pasa por esos puntos — el mismo método que se usa para ajustar cualquier función a datos experimentales. El eje Y se invierte para que la ecuación tenga la forma habitual de un tiro (a negativo, abre hacia abajo).

Todo el procesamiento se hace en el navegador — el video no se sube a ningún servidor.
